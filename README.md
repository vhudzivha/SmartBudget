Project Overview

SmartBudget is a mobile Android application designed to help users manage their daily expenses.
The app allows users to log in, add expenses, store data, and view a summary of their spending.


 Features

* Login screen
* Add expense (amount, category, description)
* Store data using SharedPreferences
* Display expenses using RecyclerView
* Delete expenses
* Automatic total calculation


 Technologies Used

* Kotlin
* Android Studio
* XML (UI Design)
* RecyclerView
* SharedPreferences



 How the App Works

1. User logs in
2. Dashboard is displayed
3. User adds expenses
4. Data is saved locally
5. Expenses are displayed in a list
6. Total is calculated automatically

 Conclusion

The SmartBudget application demonstrates a functional budgeting system with data storage, validation, and dynamic user interface updates.
